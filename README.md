# gaokao

> 2027 高考报名全流程提醒与避坑清单

<p><img src="https://img.shields.io/badge/lang-HTML-blue?style=flat-square"/></p>

## 简介
一页看懂 2027 年高考报名：报名时间轴、报名条件、五步流程、材料清单与常见避坑提醒，用静态单页形式呈现，方便随时查阅与分享。

## 技术栈
静态 HTML / CSS / JavaScript

## 快速开始
无需构建，直接用浏览器打开 `index.html`，或本地起静态服务器：

```bash
python3 -m http.server 8000
```
